The screenreader has been installed.

Start Kodi now. The screenreader starts speaking automatically.

If it stays silent (for example because Kodi was never started before), press F12 in Kodi to turn it on. On Mac keyboards this is usually fn+F12.

Keys

  • F1: repeat
  • F2: extra information
  • F3: extra item information
  • F4: stop speech
  • F6: screenreader settings
  • F12: toggle the screenreader
  • Ctrl+Plus / Ctrl+Minus: volume up / down

To uninstall, run sudo "/Library/Application Support/Kodi Screenreader/uninstall.sh" in Terminal.
