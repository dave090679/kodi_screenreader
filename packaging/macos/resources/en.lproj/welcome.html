Kodi Screenreader for macOS

This installs the Kodi screenreader (service.xbmc.tts). Kodi will then read menus, lists and dialogs aloud.

For every user who uses Kodi, the installer sets up:

  • the screenreader addon in the Kodi folder,
  • the keyboard shortcuts (F1 to F12),
  • the addon activation, so it speaks the next time Kodi starts,
  • the "Accessibility setup": on the next Kodi start it tidies up the home menu (opened with Enter only), prefers audio description, turns off the mouse, sets up the German public TV and radio stations and adds favourites for installed streaming add-ons.

Kodi must be installed and not running. If Kodi is running, quit it with Command+Q.

Speech uses the macOS voice (say). If VoiceOver is running and "Allow VoiceOver to be controlled with AppleScript" is enabled, VoiceOver can also be selected in the screenreader settings.
